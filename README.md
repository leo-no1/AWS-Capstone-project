# AWS Capstone Project

This repository contains the AWS capstone project for building, deploying, and managing a cloud-native solution on Amazon Web Services.

## Overview

The project demonstrates how to:

- Provision AWS infrastructure using Infrastructure as Code
- Deploy application services to AWS
- Use managed services for compute, storage, networking, and monitoring
- Follow secure and production-ready deployment practices

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/leo-no1/AWS-Capstone-project.git
   cd AWS-Capstone-project
   ```
2. Set up your AWS credentials and preferred region.
3. Add infrastructure and application files as needed for your solution.
4. Deploy the project using your chosen AWS tooling.

## Prerequisites

- AWS account
- AWS CLI configured
- Terraform or CloudFormation (if used)
- Git
- Code editor or IDE
